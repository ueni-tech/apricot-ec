# はじめに

このプロジェクトは、web制作勉強時期に自作した静的ECサイト（HTML/CSS/jQuery）を  
**Next.js（App Router） + SCSS Modules** を用いて再構築したものです。

UIの再現だけでなく、  
**データ構造化・コンポーネント分割・運用改善を意識したリファクタリングプロジェクト** です。

---

## 公開URL

- トップページ
https://apricot-ec.vercel.app/

- 商品詳細ページ（動的ルーティング、データ駆動のページ生成）
https://apricot-ec.vercel.app/items/136321

※トップページの「新着アイテム」のサムネイルをクリックすると動的ルーティング、データ駆動のページ生成によって商品詳細ページに遷移します

---

## 概要

- もともと自作した静的ECサイト（複数ページ・商品一覧・詳細ページ・スライダー）がベース
- 静的HTML → Next.js（App Router）構成に全面リプレイス
- jQueryベースのギャラリー／スライダー → Reactコンポーネント化
- CSS → SCSS Modules に移行し、コンポーネント単位でスコープ管理
- データ（商品・カテゴリ）を JSON に構造化して、UIロジックを分離
- レイアウト／コンポーネント責務の整理による可読性・保守性向上

## このプロジェクトで学習したこと

このリファクタリングでは以下の内容を学習しました：

### 1. **UIをReact/Next.jsで再構築し実務的なコンポーネント設計を実装**

- 複数ページを Next.js App Router で構成
- 各ページで表示される Header / Footer / CategoryNav / ProductCard をコンポーネント化して保守性を向上

### 2. **静的HTMLで混在していたデータを分離・集約**

- 静的HTMLでは各ページにハードコーディングしていた商品情報をJSONデータとして切り出し、それを各ページで読み込み、描画するように設計（実務ではDB連携する部分をポートフォリオ用として簡素化）
- data/products.json
- data/categories.json

### 3. **SCSS Modules によりスタイルの責務を明確化**

- React(Next.js)のプロジェクトといえばCSSフレームワーク（Tailwind等）を利用したスタイリングばかりを経験してきましたが、このプロジェクトではCSSファイルを利用したスクラッチのスタリングを実践しました。
- 既存 style.css（2000行超）を分割・整理
- サイトのベースとなるスタイルはコンポーネント間を跨ぐセレクタはグローバルCSSとし、各コンポーネント独自のスタイルはCSS Module(SCSS Module)を使用してスコープを制限

### 4. **動的ルーティングとデータ駆動のページ生成**

- `app/items/[id]/page.tsx`で動的ルーティングを実装し、商品IDに基づいて各商品ページを自動生成
- `generateMetadata`関数により、商品データからページタイトルや説明文を動的に生成（SEO最適化）
- 商品データ（products.json）を読み込み、存在しない商品IDの場合は`notFound()`で404ページを表示

### 5. **jQuery依存からの脱却**

- slick → React Swiper に置き換え
- DOM操作から React 的な状態管理へ移行

### 6. **Next.js固有の実務知識の習得**

- layout.tsx（共通レイアウト）
- metadata API（SEO）
- 動的ルーティング
- サーバーコンポーネント、クライアントコンポーネントの理解
- CRS、SSR、SSGの理解

## プロジェクト構成

```
apricot-ec/
├── app/                    # Next.js App Router のページ
│   ├── items/[id]/        # 商品詳細ページ（動的ルーティング）
│   ├── search/             # 商品検索ページ
│   ├── layout.tsx          # 共通レイアウト
│   └── page.tsx            # トップページ
├── components/             # Reactコンポーネント
│   ├── Header/             # ヘッダーコンポーネント
│   ├── Footer/             # フッターコンポーネント
│   ├── ProductCard/        # 商品カードコンポーネント
│   └── ...                 # その他のコンポーネント
├── data/                   # JSONデータファイル
│   ├── products.json       # 商品データ
│   └── categories.json     # カテゴリデータ
├── lib/                    # ユーティリティ関数
│   └── products.ts         # 商品データ取得関数
├── styles/                 # グローバルSCSS
│   ├── _variables.scss     # SCSS変数
│   └── _mixins.scss        # SCSSミックスイン
└── types/                  # TypeScript型定義
    ├── Product.ts
    └── Category.ts
```

## 開発で苦労した点・学んだこと

### 苦労した点

- **既存のjQueryコードの理解とReactへの変換**: DOM操作ベースのJS処理をReactの状態管理等に変換しなければならないことを学びました。
- **SCSS Modulesのスコープ管理**: CSSをコンポーネント単位に分割する際、グローバルスタイルとモジュールスタイルの使い分けを学びました
- **動的ルーティングの実装**: Next.jsの`generateMetadata`や`notFound()`など、サーバーコンポーネント特有のAPIの理解に時間がかかりました

### 学んだこと

- **コンポーネント設計**: 再利用可能なコンポーネントを作ることで、コードの重複を減らし保守性が向上することを実感しました
- **データとUIの分離**: JSONデータとして商品情報を管理することで、UIの変更が容易になり、将来的なDB連携も想定しやすくなりました
- **TypeScriptの型安全性**: 型定義を適切に行うことで、開発時のエラーを早期に発見でき、コードの可読性も向上しました
